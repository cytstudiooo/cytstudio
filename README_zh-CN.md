## 📖 简介

**CytStudio** 是一款由独立开发者打造的嵌入式开发 IDE，探索主流工具之外的另一种可能。它试图把 AI 编码智能体、硬件感知的调试器、静态代码分析与日常工程工具整合到一起——不是为了取代你已经信赖的工具，而是提供一个值得一试的新选择。

如果你在开发 ARM Cortex-M、FreeRTOS 或裸机项目，CytStudio 支持从 CubeMX、IAR、Keil 导入工程、CMSIS-Pack 组件管理、J-Link 调试与 FreeRTOS 感知、基于 FLM 的片上烧录，以及一个能陪你一起读、写、构建、调试代码的 AI 智能体。这是一个个人项目，永远在路上，也永远欢迎反馈。

## ✨ 核心特性

### 🤖 AI 智能体
- **DeepSeek Harness (dsh)**：内置 AI 编码智能体，可以陪你读写、构建、调试代码。随安装包内置，离线可用、无需额外安装，取代了此前的 CytMind 聊天面板。
- **多模型接入**：通过 dsh LLM 层接入 DeepSeek、Pi 等模型，支持重试
- **丰富的工具系统**：文件操作、bash/PowerShell、Web 搜索、终端、目标/待办跟踪等，都能直接在聊天里调用
- **子智能体与工作流**：任务可拆给多个嵌套子智能体（内置 Claude Code 与 Codex），并编排多步骤工作流
- **插件市场（dshmarket）**：在 IDE 内浏览、安装与管理智能体插件
- **MCP 客户端**：完整支持 Model Context Protocol 客户端
- **技能系统**：用户自定义与工程级技能，支持热重载
- **会话**：持久化、可检索的会话，自动标题、检查点与日志导出
- **权限与沙箱**：信任梯度权限预设 + 用户确认对话框；沙箱化的 bash / PowerShell / 文件系统执行
- **IDE 工具桥**：智能体可直接在聊天里调用 28+ 种 IDE 功能——构建、J-Link 调试、Excel、工程配置、编辑器操作、工程管理等
- **工程管理工具**：直接从智能体切换、打开或新建工程
- **工作区与主题同步**：智能体面板自动跟随当前工作区，并即时匹配 IDE 主题
- **IDE 事件注入**：编译失败或命中断点时，智能体会被唤醒并带上相关上下文

### 🔍 代码分析（优化中）
- **静态分析（clang-tidy）**：工程菜单的项目级静态分析——勾选要扫描的文件与检查类别，结果实时流入结构化输出面板，双击任一条诊断即可跳转到源码位置；可导出自包含的 HTML 报告（文件数/错误/警告/提示摘要 + 检查类别柱状图 + 代码上下文）。
- **调用图**：可交互的调用图，支持展开/折叠
- **控制流图**：逐函数 CFG 提取与可视化
- **代码度量**：圈复杂度、Halstead 度量、嵌套深度、代码行数
- **重复检测**：跨文件重复代码检测
- **继承/包含分析**：类继承层次与包含图可视化
- **导出**：图片（PNG/SVG）、HTML 报告、CSV 数据导出

### 🐛 硬件调试器
- **J-Link 接口**：完整的 J-Link 集成
- **FreeRTOS 仪表盘**：任务列表、栈用量、运行统计
- **断点与监视点**：条件断点、数据监视点
- **变量查看**：树形实时变量视图
- **反汇编**：源码/汇编混合视图
- **内存视图**：可配置列数的十六进制转储
- **寄存器视图**：CPU 与外设寄存器查看
- **调用栈**：精确的帧级栈回溯
- **高速采样**：微秒级数据采样与波形
- **探针无关设计**：下载、擦除、启动在不同调试探针下保持一致，也便于日后扩展更多调试器支持

### 💾 CMSIS-Pack 与烧录编程
- **CMSIS-Pack 管理器**：浏览、安装与卸载 Pack，器件支持自动接入构建
- **组件选择**：在专属属性页中从组件树勾选（如 CMSIS-DSP）——源码、宏与包含路径直接并入构建
- **只读组件目录树**：勾选的组件以 Keil 风格呈现在工程目录树中（`CMSIS Components` → 组件 → 源文件），文件夹与文件图标叠加灰色锁徽章并带只读悬停提示；双击以只读方式打开 pack 源文件，虚拟节点仅提供只读右键菜单（无新建/重命名/删除）。打开工程或配置变更后自动同步节点。
- **RTE 构建集成**：勾选的组件直接编译进工程；每次构建重置过期的 RTE 源码
- **编辑器对齐**：CMSIS-NN/DSP 头文件不再误报红色波浪线——编辑器与构建对 pack 的理解一致
- **快速工程加载**：仅当 Pack 有变化时才重新扫描——打开工作区与构建不再从头全量扫描
- **导入进度**：Pack 安装带可取消的进度对话框——界面保持流畅，随时可中止
- **FLM 算法解析**：加载 Keil 风格 `.flm` 烧录算法及其器件布局（基址、大小、页/扇区几何）
- **FLM RAM 执行引擎**：片上 Flash 的 RAM 内编程——扇区擦除 + 页编程，按器件分配地址
- **算法自动选择**：自动为芯片挑选最佳烧录算法——优先 J-Link 内置，其次已装 Pack 的 FLM；即使找不到算法也保持可靠
- **烧录进度 UI**：可视化的下载/擦除进度与算法信息

### 📝 代码编辑器
- **基于 Clang 的补全**：上下文感知的语义补全
- **语法高亮**：大文件打开即时，编辑时颜色保持稳定
- **跳转定义**：快速、准确的跨文件导航（头文件、`extern "C"`、C++ 重载）
- **迷你地图**：代码总览迷你地图，滚动同步
- **符号大纲**：文件结构大纲，快速定位
- **多文件搜索**：工程级正则搜索与结果面板
- **Markdown、PDF 与图片**：内置快速查看器标签页，打开 Markdown 预览、PDF 与图片文件

### 🔧 构建系统
- **构建诊断**：解析编译器错误/警告并定位源码
- **异步构建**：非阻塞构建执行，流式输出
- **工程配置**：工具链与构建配置管理
- **可配置输出**：输出文件名称（默认 `Project`）与按文件/文件夹的编译优化等级覆盖，并可通过 `objcopy` 生成 `.bin`
- **CMSIS-Pack RTE 集成**：选中的 Pack 组件向每次构建贡献源码、宏与头文件路径
- **健壮的命令行**：大工程稳定链接，规避 Windows 32 KB 命令行上限

### 📦 项目管理
- **工程迁移**：从 **STM32CubeMX**、**IAR EWARM**、**Keil MDK** 导入
- **Git 集成**：内置 Git 操作、差异查看器、提交图谱
- **多标签终端**：类 VSCode 交互式终端（PowerShell / Git Bash / CMD）——右对齐标签栏、回看滚动、Tab 补全、主题适配、等宽字体
- **最近工程**：快速访问最近工程列表
- **主题系统**：明暗主题与强调色自定义

### 🌐 国际化
- **全局语言切换**：设置对话框中完整的中英双语切换
- **双翻译管线**：完整的中英双语翻译，一键刷新工具链保持最新
- **重启确认**：语言切换后友好确认并重启生效

### 📊 数据可视化
- **实时波形**：示波器风格数据绘图，带测量工具
- **图例与游标**：可高亮图例、多游标测量
- **数据导出**：波形数据 CSV 导出

### 🔐 授权与激活
- **在线激活**：硬件绑定的安全授权激活

### 🔄 更新与维护
- **应用内更新检查**：手动（`帮助 → 检查更新`）与启动时自动检查
- **智能更新弹窗**：带发布说明的**强制更新** / **跳过此版本**选项
- **单一版本源**：一个版本号使关于对话框、安装器与更新比对保持同步

## 🚀 快速开始

### 下载

从 [GitHub Releases](https://github.com/cytstudiooo/cytstudio/releases) 获取最新安装包。

- **CytStudio_Setup_Vx.x.x.exe** — 带现代向导界面的 Windows 安装包

### 系统要求

| 要求 | 最低配置 |
|------|---------|
| 操作系统 | Windows 10 / 11（x64） |
| 内存 | 4 GB |
| 磁盘 | 4 GB 可用空间 |

### 安装

1. 下载 `CytStudio_Setup_V2.4.0.exe`
2. 运行安装程序并按向导操作
3. 从桌面快捷方式或开始菜单启动
